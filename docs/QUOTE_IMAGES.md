# Quote images (mock-ups attached to a quote)

Added Nov 28 2026 by Peyton, on branch `peyton/quote-images`. **Not live until the migration is applied and the site is rebuilt.**

## What it does
- **Admin Office, open any request:** a new **Quote images** box. Pick several files (JPG, PNG, WEBP, HEIC or PDF, up to 10 MB each), see previews, remove any, then **Attach**. Files are private and saved as **draft**: the customer cannot see them.
- **Show to customer with the quote:** marks that quote *version* as sent. From then on the customer who owns the request can see exactly those images in **My Projects**, above the (placeholder) **Approve this quote** button. A sent version is frozen. To change the pictures, **Start version 2** (this is the "request changes" path).
- Ueni shop orders (Madam Allure) get no box: they have no custom quote.

## Database (`supabase/migrations/20261128030000_quote_images.sql`)
| Piece | Purpose |
| --- | --- |
| Bucket `quote-images` | Private, 10 MB, images + PDF. Admin uploads/deletes; a customer can read an object only when it belongs to a **sent** quote on their own record (signed URLs). |
| Table `quote_images` | One row per file: record (`entity_type`, `entity_id`), `quote_version`, `path`, name, type, size, `released_at` (null = draft). RLS: admin sees all; owner sees sent rows only. |
| `admin_add_quote_image`, `admin_remove_quote_image` | Admin only. Refuse changes to a version that was already sent. |
| `admin_release_quote_images(entity_type, id, version)` | The "send" step. **The `quote_sent` step should call this** so images and quote go out together. |
| `quote_images_for(entity_type, id)` | Images grouped by version (runs as the caller, so RLS decides who sees what). |

Tests: `node --test supabase/tests/db.test.mjs` (new test: "quote images ...").

## Hooks for the quote-approval work
- Customer gallery container has a placeholder `div[data-quote-approve="<number>"]` with a disabled **Approve this quote** button. Replace it with the real Approve / Request changes buttons. "Request changes" should create the next quote version.
- The My Projects card still shows the **Pay** buttons as soon as a quote exists. The new flow wants no payment request before the customer approves, so gate `can_pay` on approval.
- `quote_images.quote_version` is not yet tied to any version column on `orders`. If the approval work adds a quote-versions table, point `quote_version` at it.

## Known limits
- HEIC photos upload fine but only Safari can draw them. In other browsers the tile shows "No preview" and the file name; clicking still opens the file. Ask for JPG/PNG when possible.
- `supabase/setup-all.sql` is not regenerated by this PR (the live project was set up from it). Apply the migration file on its own.
- The built bundle (`suites/app.js`, `suites/styles.css`) is not in the PR, to avoid conflicts. Run `npm run build` after merging.
